# Contributing

1. Measure first. A dashboard gif is not a PR.
2. New detectors go in metrics/detectors.json with an audit id.
3. Speech changes must keep compute-or-silent (no recipe recitation).
4. Do not add pip dependencies to the core loop without a flag.
5. Do not weaken fail-closed HID / bind defaults.
6. If you think it woke up, attach metrics.jsonl and go to bed.
